# 实验记录说明

验证集结果来自训练末尾对best.pt的验证日志；CSV末轮是当轮指标，可能与最终best.pt验证略有差异。30轮CSV中第28轮mAP50-95最高。

独立测试报告中270张、633个目标，mAP50=0.728、mAP50-95=0.427，数字按控制台舍入值保存。原始评估已正常完成，报告最初保存遇numpy int64序列化错误，随后从控制台输出恢复，未重跑测试，也未将测试成绩用于模型选择。

ONNX报告是用户复现后现存的最新一轮记录，纯模型计算中位PyTorch=20.0282ms、ONNX Runtime=6.8140ms。先前运行曾测得24.8/10.5ms，差异反映设备负载及测量波动；README采用当前报告，避免混用。测速在同一张验证图片输入上预热5次后各30次，batch1、CPU四线程；不是完整六图平均、端到端延时或稳定生产吞吐量。

JSON中的路径已替换为可移植的相对路径；保留的SHA256属于实际本地实验产物。数据和模型二进制未随仓库发布，复现后模型哈希不保证一致。

准备脚本和ONNX核验脚本可直接从仓库根目录运行；环境复现、数据划分、模型效果与格式一致性是不同层面的检查，不把单图一致性当成全量准确率等价。
